# PINNs
Dedicated repository to the investigation of PINNs efficiency in rumour and disease spreading in extreme data scarcity scenarios.

![SIR-Maki-Thompson](https://github.com/DiegoH81/PINNs/blob/80e0c93e68c927cade5de1f111a1f99b41b9cd8a/img/MT_partial.png)

## Repository content
- `/threading_simulations` - Multiple scripts to simulate the network in different scenarios to ensure reliability.
- `NeuralNetworks.ipynb` - Neural network implementation inspired from micrograd.
- `GENERAL.ipynb` - GENERAL model implemented with PyTorch, can handle either Maki-Thompson or SIR.
- `SIR_AQP.ipynb` - Application using real data from Arequipa-Perú, during COVID-19 epidemic.
- `SIR_CONTROL.ipynb` - SIR implementation using control theory.
- `graph.ipynb` - Data visualization.
